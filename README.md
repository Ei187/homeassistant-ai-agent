# 🤖 AI Agent Pro for Home Assistant

סוכן AI אוטונומי, מהיר ומאובטח ל-Home Assistant התומך בכל ספקי ה-AI בעולם, חיבור מודלי שפה עתידיים, שליטה מלאה בכל מכשירי הבית, ניתוח לוגים ויצירת אוטומציות במנגנון אישורים קפדני (Human-in-the-Loop).

---

## ✨ תכונות עיקריות

1. **שליטה ישירה בכל מכשירי הבית (Device Control & Smart Assist):**
   - הסוכן מזהה אוטומטית את כל הישויות, החדרים והמכשירים בבית (תאורה, מזגנים, דוד, מתגים, תריסים, חיישנים).
   - תומך בהוראות טבעיות בעברית: *"תדליק את האור בחדר של אמא"*, *"תכבה את הדוד"*, *"מה דולק עכשיו בבית?"*, *"כבה את כל האורות"*.

2. **שימוש ישיר ללא צורך בהוספה לדאשבורד (Zero-Dashboard Requirement):**
   - 📌 **סרגל הצד השמאלי (Sidebar):** לשונית **AI Agent Pro** מופיעה ישירות בתפריט הראשי של Home Assistant ומכילה ממשק צ'אט מלא, כפתור ה-`+` ומגירת ההגדרות.
   - ⚙️ **הגדרות האינטגרציה (Options Flow):** הגדרה נוחה של API Key, ספק, מודל ורמות חשיבה דרך:
     `Settings (הגדרות) ➔ Devices & Services (מכשירים ושירותים) ➔ AI Agent Pro ➔ Configure (קבע תצורה)`.
   - 💬 **Assist המובנה של Home Assistant:** ניתן לשוחח עם הסוכן ישירות דרך אייקון בועת הדיבור בראש המסך.
   - 🎴 **כרטיס Lovelace ייעודי (אופציונלי):** ניתן להוסיף כרטיס מעוצב לדאשבורד עם `type: custom:ai-agent-card`.

3. **כפתור ה-`+` ומגירת ההגדרות:**
   - לחיצה על ה-`+` ליד שורת ההקלדה פותחת מגירת שליטה עם 5 מלבני בחירה:
     1. **תפקיד הסוכן:** סוכן-על שעושה הכל / דיאגנוסטיקה / אוטומציות / מנהל בית.
     2. **ספק (Provider):** OpenAI, Google Gemini, Anthropic Claude, DeepSeek, OpenRouter, Custom (Ollama).
     3. **בחירת מודל פתוחה:** הקלדה והדבקה חופשית של כל מודל (כגון `gpt-6-astra`, `claude-3-7-sonnet`, `deepseek-r1`).
     4. **בורר רמות חשיבה אוניברסלי:** מ-`Off` (תגובה מיידית) ועד `Max` (חשיבה מקסימלית).
     5. **מפתח API:** הדבקה קלה ומאובטחת.

4. **מנגנון חשיבה גמיש (Reasoning Fallback with Transparent Notice):**
   - בחרת רמת חשיבה שהמודל אינו תומך בה? המערכת מתאימה אוטומטית לרמה הנתמכת הגבוהה ביותר ומציגה התראה שקופה בצ'אט.

5. **מצב מקומי חינמי (Zero API Key):**
   - אין לך מפתח API? הסוכן מסוגל לשלוט במכשירים מקומית, לבדוק שגיאות בלוגים ולהכין אוטומציות מיד לאחר ההתקנה!

## 🚀 הוראות התקנה ב-HACS

### שלב 1: הוספת המאגר ל-HACS
1. ב-Home Assistant היכנס אל **HACS**.
2. לחץ על **3 הנקודות** בפינה העליונה ➔ בחר ב-**Custom repositories** (מאגרים מותאמים אישית).
3. בשדה **Repository** הדבק:
   ```text
   https://github.com/Ei187/homeassistant-ai-agent
   ```
4. בשדה **Type (סוג)** בחר: **Integration**.
5. לחץ **Add**.
6. חפש **AI Agent Pro**, לחץ עליו ולחץ על **Download** (גרסה 1.2.0).

### שלב 2: הפעלה מחדש
היכנס אל **Developer Tools ➔ Restart** ובצע הפעלה מחדש של השרת.

### שלב 3: הפעלת האינטגרציה
1. עבור אל **Settings ➔ Devices & Services ➔ Add Integration**.
2. חפש **AI Agent Pro** ולחץ **Submit** (התקנה מיידית בלחיצה אחת).

## 💡 כיצד להגדיר ולהשתמש
* **מסרגל הצד:** לחץ על **AI Agent Pro** בתפריט השמאלי של Home Assistant. לחץ על כפתור ה-`+` ליד שורת השיחה והזן מפתח API או שנה הגדרות.
* **מתוך מסך האינטגרציה:** לחץ על **Configure** בכרטיס האינטגרציה תחת Devices & Services.
* **ב-Assist הראשי:** לחץ על אייקון בועת הדיבור או המיקרופון בראש המסך ובחר ב-`AI Agent Pro`.
